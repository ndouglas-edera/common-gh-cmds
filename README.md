# common-gh-cmds
Bunch of random Github commands I'll probably need in the future

```
brew install gh
```

```
gh auth login
```

or my preferred method:

```
gh auth login --web
```

```
gh auth status
```

That last command explicitly configures Git to use GitHub CLI as its credential helper.
